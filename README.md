STUDENT MANAGEMENT SYSTEM:
A Student Management System developed using **Python**, **Tkinter**, and **MySQL**. This desktop application provides a user-friendly interface to efficiently manage student records.

FEATURES:
- Login Authentication
- Connect to MySQL Database
- Add Student
- Search Student
- Update Student
- Delete Student
- Display All Student Records
- Export Student Data to CSV

TECHNOLOGIES USED:
- Python
- Tkinter
- MySQL
- mysql-connector-python
- Pillow (PIL)
- CSV

HOW TO RUN:
1. Install Python.
2. Install MySQL Server.
3. Install the required Python packages:
      pip install mysql-connector-python
      pip install pillow

4. Create the MySQL database and required table.
5. Run the application:
      python login.py
